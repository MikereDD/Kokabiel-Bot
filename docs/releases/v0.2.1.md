# Kokabiel v0.2.1

## Private Member Imports & Import Undo

Kokabiel expands its tracker import workflow to ordinary members
of explicitly authorized Telegram groups while preserving private
interaction and existing owner-only administrative boundaries.

## What's new

### Private member imports

Request `/import` from an authorized group. Kokabiel opens a
private import session with the requesting member.

Supported native tracker exports include IMDb, Letterboxd,
Trakt, and Simkl.

Uploaded files, import previews, confirmations, progress
messages, and import results are handled privately.

If Telegram prevents Kokabiel from initiating a private
conversation, a private activation link may be offered.

Ordinary members do not receive unrestricted private-command
access or owner privileges.

### Import history and undo

The private import prompt provides Import History and Cancel
Import controls.

Completed journaled imports can be selected for an undo preview.
Kokabiel identifies which titles can safely return to their
pre-import personal state and which must be preserved.

Undo requires explicit confirmation.

Personal records modified after an import are conservatively
protected from automatic reversal. Other members' records,
shared media metadata, and group associations remain intact.

Cancellation discards an unfinished import session without
erasing previously committed records.

### Reliability improvements

- Valid sessions survive competing import and undo writers.
- Busy operations provide appropriate retry feedback.
- Idle import sessions can be cancelled safely.
- Viewing unchanged television progress no longer unnecessarily
  invalidates import undo eligibility.
- Genuine changes to personal viewing state remain protected.

## Database upgrade

The upgrade introduces two import journal tables, nine journal
triggers, and two indexes.

The migration is additive and repeatable. Existing personal
media records and shared catalog records are preserved.

Back up the current database before upgrading.

Imports completed before journal support have no reliable
per-import provenance and cannot be automatically undone.

## Authorization requirements

- Configure the intended groups in `ALLOWED_CHAT_IDS`.
- Ordinary member imports require a nonempty explicit allowlist.
- Current Telegram group membership must be verifiable.
- Telegram only guarantees membership lookups for other users
  when the bot is a group administrator.
- General private-chat and administrative access remains owner-only.

## Important limitations

- Member import sessions expire after 24 hours.
- Private activation links expire after ten minutes and are single-use.
- Subsequent title changes may prevent automatic undo.
- A successful partial undo closes its selected import batch.
- Imports remain part of the user's global personal media library.
  Existing group watchlist and aggregate-rating behavior is retained.
- Undo is not permanent account-data erasure. Journal records
  and database backups may retain historical personal values.

## Supported runtime

Python 3.11 or newer on the supported Linux deployment environment.
Kokabiel's production runtime remains ARAKIEL, a Raspberry Pi 5
running Arch Linux ARM.
