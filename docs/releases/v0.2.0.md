# Kokabiel v0.2.0

## Personal Media Library & Release Intelligence

Kokabiel is a command-driven Telegram guide for films,
television series and documentaries.

Version 0.2.0 introduces a complete personal media library,
persistent release intelligence and a conservative tracker
import engine.

## Release highlights

### Personal media library

- Browse personal titles with complete pagination.
- Filter films, television series and documentaries.
- Manage personal watchlists, ratings and viewing progress.
- Sort collections by title, activity, addition date,
  release year or rating.
- Retrieve released episode totals for series on the
  current progress page.
- Navigate title actions through personal inline menus.

### Release intelligence

- Original and regional film release information.
- Series lifecycle and upcoming episode information.
- Personal release schedules with 7, 30 and 90-day windows.
- Persistent, region-scoped release metadata caching.
- User-initiated single-batch and multi-batch refresh.
- Background progress reporting.
- Cached schedule navigation without repeated TMDB requests.

### Tracker imports

- Native IMDb, Letterboxd, Trakt and Simkl import support.
- Conservative media identity resolution.
- Private previews before database changes.
- Selective approval of verified records.
- Protection against duplicate and conflicting records.
- Transactional import application.
- Verified pre-import database backups.
- Background import processing and progress feedback.

### Reliability

- Stale personal action buttons are invalidated after mutation.
- Release metadata can recover following clock correction.
- Failed metadata requests no longer monopolize successive
  refresh batches within the same running worker.
- Mixed-format personal timestamps are sorted chronologically.
- Graceful shutdown and restart handling.

## Commands

| Command | Description |
| --- | --- |
| /mylibrary | Browse the personal media library |
| /mywatchlist | Browse the personal watchlist |
| /watched | Browse watched and completed titles |
| /myprogress | Browse personal viewing progress |
| /myratings | Browse personal ratings |
| /myreleases | View upcoming tracked releases |
| /import | Import tracker exports |

Existing discovery and group commands remain available.

## Upgrade information

Version 0.2.0 adds a persistent release_cache table to
the existing SQLite database.

Create a verified database backup before upgrading.

Existing external configuration and virtual environments
can be retained when compatible with the requirements.

See the README and media library documentation for
deployment instructions and refresh behavior.

## Validation

The implementation was validated on native ARM Linux
with Python 3.14.7 and SQLite 3.53.4.

- 434 automated regression tests passed.
- Five independent acceptance tests passed.
- Database migration was tested for repeatability.
- Live private Telegram library and release schedule
  functionality was exercised.
- Full live metadata refresh and cache persistence
  were verified.
- Existing episode history, ratings, watchlists and
  viewing status were preserved.
- Repeat-import safety and restart persistence were
  verified against an existing database.

## Known limitations

- Group-specific live acceptance and some library actions
  have not been exhaustively exercised.
- Import identity review reports unresolved items but does
  not provide a complete interactive resolution dashboard.
- Refresh-all is bounded by request and batch-start budgets.
- Failed-request retry history is maintained in memory
  and resets when the refresh worker is recreated.
- An intermittent disappearing refresh message was reported
  during live testing but was not independently reproduced.
- TMDB release information may change and may not include
  every future episode or regional release.
- Release metadata does not guarantee streaming availability.

Refresh operations are user-initiated. Kokabiel does not
send unsolicited release notifications or inspect ordinary
group conversations.
