# Third-Party Attribution

Kokabiel uses third-party APIs, data, images, and libraries. Those materials
are not covered by Kokabiel's source-code license notice.

## The Movie Database (TMDB)

TMDB is Kokabiel's primary source for film and television metadata and images.

> This product uses the TMDB API but is not endorsed or certified by TMDB.

Kokabiel includes an approved TMDB logo in its About/Credits presentation. The
TMDB mark remains secondary to Kokabiel's identity and is not intentionally
recolored, distorted, flipped, or rotated.

- TMDB: https://www.themoviedb.org/
- Logo and attribution guidance: https://www.themoviedb.org/about/logos-attribution

## JustWatch

Streaming, rental, and purchase availability returned through TMDB's watch
provider endpoints is sourced from JustWatch. Kokabiel attributes JustWatch
when provider availability is displayed.

- JustWatch: https://www.justwatch.com/
